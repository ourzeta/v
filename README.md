# 讲题视频工作台（Next.js 版）· 使用说明书

给小学数学老师 / 家长的 AI 讲题工具：**拍一道题 → 自动生成分步讲解（口播 + 手写板书）→ 一键配音 → 录成讲题视频**。

> 本项目免费开放使用，**开箱即用、零配置**——AI 识别 / 讲解生成 / 语音合成的密钥已内置在代码里，无需申请、无需填任何参数。

---

## 一、快速上手（三步出片）

1. **上传题目**：打开网页 → 拍照 / 上传题目图片（也可以直接手填题干）→ 点「识别」
2. **生成讲解**：确认题目后进入分镜表，点「生成」自动产出五字段（环节 / 口播稿 / 板书 / 动作 / 时长），不满意可整表重新生成或逐格手改
3. **出片**：
   - 点 **「一键语音」**：并发 3 路批量给所有行配音（绿勾 = 完成，失败行点行内 ↻ 重试）
   - 点 **「生成交付单页」**：得到离线播放页（音频 / 题目图随包）
   - 打开交付单页 → **1 ▶ 播放 → 2 ✍ 批注 → 3 ● 录制** → 得到讲题视频（WebM）

## 二、各功能区速查

| 位置 | 干什么用 |
|---|---|
| 第 1 步（上传 / 识别） | 题目图识别、知识点抽取、板书布局预览（📐 可拖拽调整） |
| 分镜表（Agent B） | 每行 = 一段讲解：口播稿、板书内容、强调动作、语音 |
| 「一键语音」按钮 | 批量补齐全部缺失行的配音（并发 3，对齐 3 枚 key 轮询） |
| Check Agent | 自动校对五字段（除号 / 分数 / 口播一致性），弹窗给修正建议 |
| 交付弹窗 | 下载离线播放页 / 标准 ZIP 交付包（解压双击即播，含字体） |
| 播放页（lite player） | 1 播放 → 2 批注 → 3 录制，支持四区手写字体切换 |

## 三、使用约定（双向尊重）

工具保证音色不串音，也请使用者遵守：

1. 先选音色，再生成。
2. 一条视频只用一种音色。
3. 中途换音色需重新生成。
4. 交付前确认音色一致。

> 界面音色下拉旁的「约定」可随时查看。

## 四、常见问题

- **识别不准 / 识别失败**：图片拍清楚一点（题干完整、光线充足）；或直接手填题干跳过识别
- **语音失败 / 某行没声**：多为免费接口瞬时限流，点该行 ↻ 重试即可；失败行汇总提示会告诉你是哪几行
- **录制没有声音**：录制走系统音频，需允许浏览器「分享标签页音频」；导出 WebM 后如需 MP4 请用任意在线转换器
- **除号 / 分数显示**：板书用内部记法（除号 `.-.`、分数 `7/15`），程序统一渲染成手写体，导出物自动转回 ÷ 与 a/b 给人看，无需手改

## 五、部署（给部署者）

零配置部署：密钥已内置代码，**不依赖任何 .env**（提供 env 仅作覆盖，见 DEPLOY.md）。

```bash
bun install          # 安装依赖
bun run build        # 构建（standalone 产物）
bun run start        # 启动（默认 3000 端口）
```

数据库为 SQLite（Prisma），首次启动自动就位；历史产物存 `var/` 与 `public/audio-cache/`。详细部署口径（目录职责 / 反代 / 验收）见 [DEPLOY.md](./DEPLOY.md)。

## 五、本地运行（Windows）

在本项目目录打开终端，首次安装依赖后启动：

```powershell
bun install --frozen-lockfile
npm run dev
```

浏览器打开 http://127.0.0.1:3000/。本机本轮已保持后台运行，开发日志在 dev.out.log 和 dev.err.log。

若安装停在 Prisma 引擎下载，当前工作台首页可用 bun install --frozen-lockfile --ignore-scripts 安装页面依赖；该方式不代表数据库生成已完成。现有数据库生成入口为 npm run db:generate。
